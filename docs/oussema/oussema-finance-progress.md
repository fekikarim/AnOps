## Pending / open questions
- **`vite-node` is not in `package.json`**, but the project's scripts (`telegram:poll`, `marketing:seed-demo`, `finance:seed-demo`, `finance:ocr-check`) call it, so `npm run …` fails on a fresh install. Adding it as a devDependency (`npm i -D vite-node`) fixes it for the whole team; until then use `npx vite-node -c vitest.config.mts scripts/<file>.ts -- …`.
- **Timbre fiscal amount:** set to 1.000 TND (`TIMBRE_FISCAL_TND`). Please confirm with your accountant that it's current for 2026.
- **Live Telegram test (Oussema, on production):** `APP_URL` is not set, so no webhook; locally, receipts sent to the bot arrive only while `npm run telegram:poll` runs. The bot is shared with Marketing (Nesrine): only one poller or webhook can be active at a time. In production, set `APP_URL` to the public HTTPS address and register the webhook from Marketing › Integrations.
- **Before deploying F0.5:** the unique invoice-number index fails to build if an existing database already contains two invoices with the same number in one company, and `ensureIndexes` would then report "Database is not ready". Numbers come from a counter, so this is unlikely, but check the real database once (an aggregation on `finance_invoices` grouped by `companyId` + `invoiceNumber`, keeping groups with count > 1).
- Groq's free tier hits rate limits quickly (a 429 after a few calls in a row). For real use, add a Gemini key as well: it's the first choice for vision and the only one that reads PDFs.
- **Add `GEMINI_API_KEYS` to `.env` to scan PDFs.** Without it only images work, through Groq; PDFs fail with "No configured AI provider can read this file type". A free key comes from Google AI Studio.
- 3 unit tests fail on Windows **with or without these changes** (`ai-gate-guard`, `ai data scope`, `transcript audit`): they compare paths with `/` while Windows gives `\`. Not caused by this work; worth a separate small fix.
- Tests run against a disposable local replica set (`mongod --replSet rs0 --port 27018`), matching `tests/helpers/workspace.ts`.
